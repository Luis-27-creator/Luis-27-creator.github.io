AutoPartes MX

Landing Page para empresa de refacciones automotrices

Descripción

AutoPartes MX es una tienda local de refacciones y piezas automotrices que busca modernizar su presencia digital. Se propone desarrollar un prototipo responsivo de 3 páginas (Inicio, Catálogo, Contacto) que muestre la identidad de la empresa, parte del catálogo y un formulario de contacto con validación y eventos en JavaScript. El prototipo demostrará uso de HTML, CSS, Bootstrap y JavaScript, incluyendo tablas, formularios y al menos dos eventos interactivos.

Objetivo del prototipo

Diseñar y construir un sitio web de 3 páginas enlazadas que:

  • Presente la empresa y su misión.
  • Muestre un catálogo con tabla de productos y productos destacados en tarjetas.
  • Incluya un formulario de contacto con validación y confirmación de envío.
  • Sea responsivo y personalizado con CSS propio y uso del sistema de grid de Bootstrap.

Tecnologías Utilizadas

HTML5 estructura semántica

CSS personalizado

Bootstrap responsive

JavaScript validaciones DOM
