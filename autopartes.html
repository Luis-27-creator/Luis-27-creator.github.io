AutoPartes MX

Landing Page para empresa de refacciones automotrices

Descripción

AutoPartes MX es una landing page diseñada para una empresa local especializada en la venta de refacciones y piezas automotrices. El sitio comunica la misión de la empresa, su catálogo, ventajas competitivas y ofrece contacto directo con clientes.

Tecnologías Utilizadas

HTML5 para estructura semántica y accesibilidad.

CSS personalizado para identidad visual y estilos responsivos.

Bootstrap para grid, componentes y diseño adaptativo.

JavaScript para validaciones, eventos y manipulación del DOM.

Vistas del Proyecto

Página Inicio con encabezado y logotipo

Catálogo con tabla de productos

Catálogo con Cards en grid responsivo

Formulario de contacto con validación
